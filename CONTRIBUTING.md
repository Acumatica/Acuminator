If you want to contribute a new diagnostic or feature to Acuminator, first create an issue in the [GitHub repository](https://github.com/Acumatica/Acuminator/issues) and describe the feature that you want to implement.
This will allow us to discuss the implementation and ensure that it aligns with the project's goals. 

**All new diagnostics must be approved by Acumatica before the implementation.**
